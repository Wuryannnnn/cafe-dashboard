## 一、产品概述

面向咖啡店的点餐与后台管理系统，覆盖"菜品管理 → 扫码点餐 → 订单处理 → 结账收银 → 会员营销 → 经营分析"全链路。**所有管理功能均由店主/店长在后台自行操作**，支持完整的增删改查。

## 三、菜品管理

> 参考：美团管家 → 运营中心 → 菜品管理
> 店主可完全自主管理，支持增删改查

### 3.1 菜品库

管理门店所有在售/停售菜品，是系统最核心的功能。

**页面结构**：
- 顶部操作栏：创建菜品 | 创建套餐 | 菜品排序 | 导入菜品 | 批量操作
- 左侧：分类导航树（点击筛选）
- 右侧：菜品列表表格
- 搜索：支持按名称、编码、条形码搜索
- 筛选：支持展开高级筛选

**菜品列表展示字段**：
- 序号、菜品名称、菜品分类、菜品类型（普通菜/套餐）、价格、操作

**店主可执行的操作**：
| 操作 | 说明 |
|------|------|
| 创建菜品 | 填写名称、选择分类、设置规格和价格、上传图片 |
| 编辑菜品 | 修改菜品的任何信息 |
| 复制菜品 | 基于已有菜品快速创建相似菜品 |
| 删除菜品 | 删除不再需要的菜品 |
| 停售/起售 | 临时下架或重新上架菜品 |
| 批量停售/删除 | 批量操作多个菜品 |
| 菜品排序 | 调整菜品在菜单中的展示顺序 |

**编辑菜品 — 详细配置项**：

| Tab | 配置内容 |
|-----|---------|
| 基础信息 | 菜品名称、菜品分类（下拉选择，支持新建）、菜品规格（规格名如中杯/大杯、基础价、会员价、预估成本）、支持多规格、菜品单位（杯/份） |
| 菜品构成 | 关联原料（用于成本核算） |
| 打印配置 | 菜品关联到哪台打印机（吧台/厨房） |
| 销售信息 | 上架渠道、销售时段 |
| 财务信息 | 财务分类 |
| 点餐端展示 | 菜品图片、描述文字、在顾客端的展示样式 |

### 3.2 菜品分类

店主自行管理菜品的分类体系。

**店主可执行的操作**：
| 操作 | 说明 |
|------|------|
| 新增分类 | 输入分类名称 |
| 编辑分类 | 修改分类名称 |
| 删除分类 | 删除空分类（有菜品关联时需先移除） |
| 排序 | 拖拽调整分类顺序（影响顾客端菜单展示） |

**典型分类示例**（咖啡店场景）：
- 咖啡类：黑咖、奶咖、手冲、冷萃、创意特调
- 饮品类：无咖饮品、茶饮
- 轻食类：甜品、欧包、三明治、小吃、主食
- 套餐类：下午茶套餐
- 加料类：换豆、换奶、加料
- 其他：餐盒

### 3.3 菜品属性（做法/加料）

管理顾客点单时可选的做法和加料项。咖啡店的核心差异化功能。

**店主可执行的操作**：
| 操作 | 说明 |
|------|------|
| 创建属性组 | 如"温度"、"甜度"、"奶类替换"、"加料" |
| 编辑属性组 | 修改名称、设置必选/可选、单选/多选 |
| 删除属性组 | 删除不需要的属性组 |
| 添加属性值 | 在属性组下添加选项（如温度→热/冰/温） |
| 设置加价 | 某些属性值可设置加价金额（如换燕麦奶+5元） |
| 关联菜品 | 将属性组关联到对应菜品（不同菜品可关联不同属性组） |

**典型属性配置**：
| 属性组 | 属性值 | 必选 | 单选/多选 | 加价 |
|--------|--------|------|----------|------|
| 温度 | 热 / 冰 / 温 | 是 | 单选 | 否 |
| 甜度 | 全糖 / 半糖 / 微糖 / 无糖 | 是 | 单选 | 否 |
| 奶类 | 鲜奶 / 燕麦奶 / 椰奶 | 否 | 单选 | 燕麦奶+5元、椰奶+5元 |
| 浓度 | 标准 / 加浓 / 减浓 | 否 | 单选 | 加浓+6元 |
| 加料 | 椰果 / 珍珠 / 芋圆 | 否 | 多选 | 各+3元 |

### 3.4 时段菜单

不同时段自动展示不同菜品组合。

**店主可执行的操作**：
| 操作 | 说明 |
|------|------|
| 创建时段 | 设置时段名称和起止时间（如"早餐 07:00-10:00"） |
| 编辑时段 | 修改时段名称和时间 |
| 删除时段 | 删除不需要的时段 |
| 关联菜品 | 勾选该时段展示的菜品 |

## 四、扫码点餐（顾客端）

> 参考：美团管家 → 手机点餐 / 手机点餐 2.0

### 4.1 顾客点餐流程

```
扫描桌台二维码
    ↓
进入菜单页（左侧分类导航 + 右侧菜品列表）
    ↓
点击菜品 → 弹出详情（规格选择、做法选择、加料选择、数量、备注）
    ↓
加入购物车
    ↓
查看购物车（修改数量/删除/清空）
    ↓
提交订单 → 选择支付方式
    ↓
支付完成 → 查看订单状态
    ↓
出品完成 → 取餐
```

### 4.2 后台点餐设置

店主可配置顾客端点餐的参数。

| 配置项 | 说明 |
|--------|------|
| 点餐开关 | 启用/关闭扫码点餐 |
| 点餐菜品管理 | 选择哪些菜品在顾客端展示，独立于店内菜品 |
| 点餐模式 | 先付后食 / 先食后付 |
| 最低消费 | 设置起点金额 |
| 自动接单 | 是否自动接受扫码订单 |

## 六、订单管理

### 6.1 订单列表

**页面功能**：
- 按时间倒序展示所有订单
- 筛选：按状态（待支付/已支付/制作中/已完成/已取消/已退款）、日期范围、订单号、桌号
- 搜索：按订单号搜索

### 6.2 订单详情

展示内容：
- 订单基本信息：订单号、下单时间、桌号、订单类型（堂食/外带）
- 菜品明细：菜品名称、规格、做法、数量、单价、小计
- 支付信息：支付方式、支付时间、实付金额
- 操作日志：订单状态变更记录

### 6.3 订单操作

| 操作 | 说明 |
|------|------|
| 接单 | 确认接受订单（如未开启自动接单） |
| 标记制作完成 | 出品后标记 |
| 取消订单 | 取消未完成的订单 |
| 退款 | 对已支付订单执行退款 |
| 改价/打折 | 修改订单金额 |

### 6.4 订单状态流转

```
顾客下单 → [待支付] → 支付成功 → [制作中] → 制作完成 → [已完成]
                ↓                    ↓
            [已取消]             [已退款]
```

## 九、报表统计

> 参考：美团管家 → 报表中心

### 9.1 经营概况（Dashboard）

首页展示核心经营指标，支持按天/周/月切换：

| 指标 | 说明 |
|------|------|
| 今日/本周/本月营业额 | 营业收入总额 |

| 营业收款 | 实际到账金额 |

| 功能 | 说明 |

| 趋势图 | 折线图展示营业额走势 |
| 支付明细 | 每笔订单的详细支付记录 |
| 导出Excel | 支持导出报表数据 |

### 9.3 菜品报表

| 功能 | 说明 |
|------|------|

| 菜品销售明细 | 每个菜品的销量、销售额、占比 |
| 按时间筛选 | 支持自定义时间范围 |
| 导出 | 支持导出 |

### 9.4 收款报表

| 功能 | 说明 |
|------|------|
| 收款方式统计 | 各支付方式（微信/支付宝/现金/会员余额）的收款金额和笔数 |
| 综合收款统计 | 按业务类型（堂食/外带）的收款汇总 |

### 9.5 财务报表

| 功能 | 说明 |
|------|------|
| 收支汇总 | 营业收入 vs 日常支出对比 |
| 收支明细 | 每笔收支的详细记录 |
